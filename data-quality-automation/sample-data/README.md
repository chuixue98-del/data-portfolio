# Data

All data here is made up. "Contoso Foods" and every name and number are fictional.

- `generator/generate_data.py` creates the files below.
- `raw/` holds the source files, in the messy shapes real systems deliver.
- `snapshots/` holds three exports of the factory list.
- `clean/` is created when you run the cleaning script. It is not stored in Git.

Some errors are added on purpose, so the checks have something to find.
